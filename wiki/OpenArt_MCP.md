# OpenArt MCP

**Installed:** 16-tool MCP for image generation.
**OAuth redirect port:** 24180
**Token:** `mcp-tokens/openart.json`
**Config:** use `hermes config set` to set oauth.redirect_port=24180
**Limits:** Credits are limited. Use sparingly.
**Preview:** Edge/Hermes preview works (not Chrome).
